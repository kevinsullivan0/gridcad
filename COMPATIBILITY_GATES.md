# Compatibility boundaries

## Passed for reversible candidate copies

- Exact input validation and explicitly reviewed geometry-linked roles/orientation.
- Versioned own EcoFlex converter, tested against independent native outputs.
- Stored Print 2191 / PolyJet 2190 schemas; descriptive patch versions preserved.
- Recognized TechStyle / PrintOnFabric / HighMix 3 profile, required six channels, optional EcoContactFlex, separate FullCure705 support and valid existing adhesion.
- Flat independent plain STL geometry; desired and actual material agreement.
- Atomic new-copy output, source preservation, complete non-material/payload audit.
- Native schema/archive readback on generated varied and benchmark outputs.

## Not equivalent to print readiness

Normal Windows GrabCAD GUI loading, full recomposition and service/live-printer material feasibility remain unverified. Source-constructed profile fixtures are not captured backend configurations. No user confirmation checkbox can make an unsupported schema or active geometry/material feature supported.

## Useful future compatibility work

Test actual user projects and normal Windows reopen/recompose. If a rejection is a passive grouping container rather than active inheritance, validate that specific hierarchy contract before enabling writes. New stored schemas need a small versioned adapter/test update, not guessed compatibility ranges. Keep unrelated descriptive fields untouched and distinguish them from active features.
