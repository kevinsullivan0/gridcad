Optional exact addresses

Visual selection fills the range automatically. You can adjust it here. Choose Reload this view after changing the jump address.

2. Check the selected recipes

One occupied cell = six channel percentages, for example 20 / 0 / 0 / 0 / 30 / 50. In CMYKWT order: cyan 20%, magenta 0%, yellow 0%, black 0%, white 30%, clear 50%. Spaces around slashes are fine; total must be exactly 100.

Rows and columns stay as shown. No workbook cells are edited. Physical label regions are reviewed separately.

Select any cell to see its original content and saved result. GridCAD never calculates formulas and cannot verify cache freshness. Missing or unsupported formula results need recalculation/save in Excel or evaluated values pasted into a workbook copy. Numeric scalars are not guessed into six channels.

Optional empty positions and numeric syntax

Use explicit 0 when possible. A blank cell is a hole, not a zero recipe. Decimal points and % signs are allowed; decimal commas and mixed separators are not inferred. Six values must sum exactly to 100. No rounding or normalization.

Select bodies by region

These are physical bodies in the .PRINT project, not Excel sidebars. For saving, select the sample bodies plus BOTH complete printed row-label and column-label regions separately. Workbook-only checks do not need these regions. Other objects are preserved.

Tray XY view in millimetres; +Y is up. Bounding boxes are not rendered meshes. Drag boundaries must enclose whole bodies. Labels are never inferred from shape alone.

What GridCAD read from Excel

Each tile is an Excel cell, not a rendered sample color. Select a tile to see its original content, saved formula result and exact channel percentages. Red cells block a candidate copy; blank cells stay holes. No changes have been made. Inspection supports up to 100,000 selected cells; larger selections are refused rather than truncated.

Select a cell to inspect C / M / Y / K / W / T.

Samples use exact CMYKWT recipes; selected glyphs use direct EcoFlex Black (not K=100). The actual source profile is checked, including optional EcoContactFlex adhesion and FullCure705 support. Four-decimal recipes are tested; values are never silently rounded.
