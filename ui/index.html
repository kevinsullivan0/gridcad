Choose the Excel tab and recipe cells

One cell = one sample recipe. Select the rectangle of recipe cells only, not the side tables or headings. Keep blank positions inside that rectangle so the grid still lines up. Formula references may point to sidebars outside your selection; leave those sidebars in the workbook.

In Excel, select just the recipe rectangle and read its first and last cell addresses. Example: B2 through F4 → B2:F4. The workbook's full used area is not necessarily the recipe grid.

Select recipe cells visually

Drag across the data grid to select the recipe rectangle, or type its range above. For a selection spanning pages, click its first cell, navigate, then Shift-click its last cell. Cells outside your selection may be headings or sidebar inputs; they are not imported. This is a data-only preview, not Excel's formatting, merged-cell layout, or calculation engine. Printed labels in the .PRINT file are selected separately on the tray.

Expected contents of one cell, in CMYKWT order

20 / 0 / 0 / 0 / 30 / 50

Cyan 20%, Magenta 0%, Yellow 0%, Black 0%, White 30%, Clear 50%. Total = 100%.

Spaces around slashes are fine. Also accepted: 20 0 0 0 30 50 or 20;0;0;0;30;50. Decimal points and % signs are allowed. Use an explicit 0 for unused channels. A completely blank cell is a grid hole, not a zero recipe.

C = cyan, M = magenta, Y = yellow, K = black, W = white, T = clear. Enter all six letters once in the order your cells actually use. Comma-separated bundles require an explicit separator choice; decimal commas and mixed separators are not inferred.

This does not edit Excel. Original cell addresses and recipes stay attached to each sample. After inspection, the recipe preview swaps dimensions and only matching transposed orientations are offered. Mirroring still requires your explicit orientation choice. Printed label regions stay where you selected them; text and row/column associations are never inferred or rewritten.

GridCAD reads saved results but never runs formulas. Saved results may be stale; their freshness cannot be verified. If a result is missing, recalculate and save in Excel, then select the file again. Alternatively paste evaluated recipes as values in a workbook copy. Keep originals unchanged.

Optional: empty channel positions

For example, 20 / / / / 30 / 50 is accepted only with this option. Six positions and an exact total of 100 are required. Nothing is normalized or rounded.

Tray XY view in millimetres; +Y is up. Bounding boxes are not rendered meshes. Drag boundaries must enclose whole bodies. Labels are never inferred from shape alone.

What GridCAD read from Excel

Each tile is an Excel cell, not a rendered sample color. Select a tile to see its original content, saved formula result and exact channel percentages. Red cells block a candidate copy; blank cells stay holes. No changes have been made. Inspection supports up to 100,000 selected cells; larger selections are refused rather than truncated.

Stored source profile (not a live printer check)

Samples use exact CMYKWT recipes; selected glyphs use direct EcoFlex Black (not K=100). The actual source profile is checked, including optional EcoContactFlex adhesion and FullCure705 support. Four-decimal recipes are tested; values are never silently rounded.

Preview shows which selected bodies would receive each recipe, which selected glyphs would receive direct EcoFlex Black, exact matches skipped, and unselected objects preserved. It does not save, print, or change your original files.
