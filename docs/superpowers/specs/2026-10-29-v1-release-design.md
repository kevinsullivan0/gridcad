# GridCAD 1.0 workflow design

The user confirms the source launcher works and delegates the 1.0 polish: editable PRINT filename, no unnecessary text/JSON files in ordinary exports, friendlier launcher, and complete release quality.

Preserve the validated converter. A desktop single-file export stages the existing writer's result and publishes the chosen PRINT only after its checks pass. An optional conversion-report checkbox adds one report. Advanced operator bundles remain unchanged. This separates validation from report delivery without weakening preservation or claiming native acceptance.

Use a normal Save As dialog with a source-derived suggestion, no forced UNVERIFIED suffix, and no overwrite. Keep concise in-app guidance to inspect in GrabCAD before printing. The native archive receives no new app metadata. Reports retain truthful file-check, physical-review and print-ready fields.

Retain the proven source launcher's verified official Python setup, consent, private environment and offline repeats. Improve setup progress and failure recovery rather than introducing a fragile bootstrap or security workaround. Both source and EXE packages include usable help, examples, licenses, matching versions and checksums. README explains installation and use, not the changelog.

Independent tests precede code. Acceptance covers file integrity, failed/canceled/repeated saves, collisions, real Windows dialogs, small windows, first/repeat setup and recovery. Native GrabCAD and printer validation remain separate; never promote archive checks into that claim. No laptop use, private-input publication, automatic updates or security-policy changes. MIT remains unchanged.
