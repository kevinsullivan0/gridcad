# GridCAD 0.2 RC1 — Windows desktop candidate

The desktop replaces the local browser launcher for the bounded rectangular labeled-grid workflow. It includes native file dialogs and controls, paged addressed Excel previews, explicit formula-cache policy, transpose/orientation selection, actual embedded-glyph geometry with zoom/pan, exact assignments, user review notes, and separate result bundles with preservation audits.

The Windows ZIP bundles its runtime and an agent CLI. The portable source core, AGENTS.md, Markdown API/schema documentation, a copyable external-agent prompt, and newly generated synthetic PRINT/XLSX/preview examples are included. No LLM or first-run dependency download is required.

The new mapper reproduces both independently reviewed private operations byte for byte, preserving all geometry/nonmaterial JSON and 2,848 / 2,812 non-project payloads. Public assets contain synthetic data only. The writer's existing guards remain active; a Windows staging-handle fix preserves the fsync and exclusive-output protections. Frozen builds carry the exact converter source so its provenance/integrity check remains active.

This is an **unsigned prerelease candidate**. Native GrabCAD opening/recomposition/save, printer suitability and physical printing remain unverified. Source/profile limitations are documented; other versions, transformations and geometries are refused. Synthetic examples are software contracts and **DO NOT PRINT** fixtures. User physical-label review remains necessary; neither file tests nor a mapping digest establishes that review.

The release's GUI acceptance evidence identifies the exact extracted ZIP tested, real native dialogs and controls exercised, original-input hash checks, complete output recipe readback, and remaining native acceptance limits. Keep previous releases and original input files.
