# Download and verify GridCAD with your own agent

Copy this into an agent you already use. It needs download/file tools; an ordinary chat may not have them. No agent is needed for manual installation.

```text
Download only GridCAD-Windows-x64-v0.2.0-rc.5.zip and SHA256SUMS.txt from
https://github.com/kevinsullivan0/gridcad/releases/tag/v0.2.0-rc.5
Use the release assets, not Source code (zip). Save into a new folder without
replacing any existing files. Compute the ZIP's SHA256 before extraction or launch
and compare it exactly with that filename's entry in the published SHA256SUMS.txt.
If either download or comparison fails, stop and report it. Report the source URLs,
local paths, expected hash, actual hash and match result. Do not extract or run the
app, install anything or change security protections automatically. A matching
checksum establishes consistency with the listed download, not safety certification.
```
