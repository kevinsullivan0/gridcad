# GridCAD contributor and external-agent contract

Goal: a usable deterministic converter for the documented rectangular labeled-grid workflow, with a portable source core. Read `docs/RECTANGULAR_SCHEMA.md`, `docs/DESKTOP_API.md`, `docs/DESKTOP_MANUAL.md` and `operator/README.md` before modifying mapping/material code.

- Keep original files and every prior output unchanged. New candidates go in a new directory; never overwrite, normalize, repair units/version fields, discard identities, or weaken guards to accept an unknown profile.
- Private customer/source files, workbooks, embedded meshes, renderings, exact plans and IDs, material comparison evidence, local paths and secrets must remain outside public commits/releases. Use newly generated synthetic fixtures only. No vendor installers, runtime, fonts, databases or private inputs may be bundled.
- Mesh-derived rectangular proposals need explicit orientation. Desktop users may save a separate unverified candidate without a physical-review attestation; record that absence truthfully. Physical printed-label review remains necessary before printing. Neither an occurrence rank nor a valid digest proves physical correspondence. Expected worksheet-derived percentages are requests, not independent OCR evidence. Preserve that distinction in docs and audits.
- Preserve nonmaterial geometry/transforms/schema/payloads, existing IDs, unrelated bodies and complete matching native materials. Existing conflicts must be resolved from evidence, never overwritten automatically.
- Keep `print_ready=false` until an appropriately revised workflow has actual native open/recompose/save evidence and explicit printer/process acceptance. Archive/schema-loader tests and a previous successful conversion do not establish full package or native acceptance.
- Run `python -m unittest discover -s operator/tests -v` and `python -m unittest discover -s tests -p test_desktop_core.py -v` for core changes. For GUI/packaging changes run the hosted Windows workflow and `tools/windows_gui_acceptance.py` against the extracted artifact. Tests must operate real file dialogs, actual controls, previews and saving; component counts alone are insufficient.
- The desktop entry is `gridcad_desktop.py`; agent CLI is `desktop_cli.py`; portable reviewed writer is `operator/gridcad_operator/`. The retired browser interface and its separate runtime/tests are preserved in the immutable `v1.0.1` tag and Git history, not maintained in the current checkout. See `docs/DEVELOPMENT.md` for the repository map and test commands.
- Original GridCAD code is MIT licensed under LICENSE, as authorized by Kevin Sullivan. Preserve upstream provenance and third-party licenses; do not relicense dependencies or publish private/native vendor material. Existing owner authorization governs publication of the app/code and synthetic examples.

Other geometries need explicit new adapters and evidence. Do not advertise unimplemented triangular, hexagonal, arbitrary 3D or universal CAD conversion.
