# GridCAD 1.0 release implementation plan

Goal: a clean, understandable conversion workflow from first launch to a named PRINT output, with tested diagnostics and honest compatibility limits.

Architecture: preserve the reviewed streaming writer and advanced audit bundle. Add a desktop single-file export layer that stages the existing validated output, publishes the chosen PRINT without overwrite, and optionally publishes a concise report. The GUI uses a normal Save As dialog and offers optional reports in Settings. Keep native acceptance warnings in the application/help rather than mandatory filename suffixes or loose warning files. Retain existing deterministic toolkit and source launcher.

User delegated implementation and polish without another design discussion. Decisions above are implementation choices, not user-specified internals.

## Tasks
- [ ] Independently freeze export/launcher contract tests before product changes.
- [ ] Add and test `desktop_core.save_print(..., include_report=False)`; preserve original writer checks, no-overwrite, input integrity and cleanup on failure.
- [ ] Replace GUI folder save with named PRINT Save As; default meaningful filename, optional report setting, truthful post-save confirmation. Update real Windows acceptance to exercise actual dialog, custom names and no sidecar clutter.
- [ ] Integrate independently implemented source launcher polish without weakening installation consent, signature/hash verification or security controls.
- [ ] Unify version 1.0 across UI/package/docs. Bundle source launcher with complete source in normal package; offer self-contained source ZIP as primary usable route. README is installation/use, not a changelog.
- [ ] Run complete regression, independent security/UI review, hosted Windows extracted GUI and source-launcher acceptance, artifact/checksum inspection. Fix failures then rerun affected full gates.
- [ ] Publish authorized v1.0.0 release only if gates pass; verify remote commit, CI, public downloads and README links. Disclose native GrabCAD/printer acceptance limits.

## Review focus
Chosen paths with spaces/nonASCII and mixed-case PRINT; collisions and racing creations; canceled/repeated save without changed state; write/validation failure without partial output; first/repeat launcher and offline setup; small-screen layout and keyboard navigation; every release entry point uses same version and included dependencies.
